# Known Good Media: brand guide

## The idea

"Now" is hidden inside "Known." The wordmark shows it as **K(NOW)N**: K and N in the base color and NOW in electric blue. It quietly says *the time is now*, and it matches the tagline **Get Known.**

## Logo files

| File | Use it for |
|---|---|
| `logo-on-dark.svg` | The main logo on black or dark photos (transparent background) |
| `logo-on-light.svg` | White paper, flyers, invoices, light website sections |
| `logo-card-dark.svg` | A self-contained black card with the tagline, for social posts and slides |
| `watermark.svg` | The corner watermark on every reel (set it to about 80% opacity) |
| `icon-k.svg` | The silent-K icon for the favicon, app-style icons and small spaces |
| `avatar.svg` | Profile picture for Instagram, TikTok, X and YouTube |

Every SVG has its text converted to shapes, so it looks the same on any computer without the fonts installed. PNG exports are in `png/`.

## Colors

| Name | Hex | Use |
|---|---|---|
| Black | `#0B0D10` | Backgrounds, text on light |
| Electric Blue | `#2F7BFF` | The NOW, buttons, accents on dark |
| Deep Blue | `#1F5FE0` | Blue on white backgrounds (easier to read) |
| White | `#FFFFFF` | Text and wordmark on dark |

## Fonts (free, from Google Fonts)

- **Anton:** the wordmark and big headlines
- **Barlow Condensed:** labels, lower-thirds, "GOOD MEDIA" and graphics
- **Barlow:** body text on the website

## Rules

- Don't recolor the K and N to match NOW. The contrast is the whole idea.
- Leave clear space around the logo at least as wide as the K.
- On busy game footage, use the watermark, not the full logo.

These files are a strong starting point. For shirts, banners and embroidery, a designer can refine them into final print-ready files.
